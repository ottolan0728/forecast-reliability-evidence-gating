# Accepted figure provenance

FIGURE_ALIASES.csv enumerates every includegraphics asset referenced by accepted main and supplementary sources, including the final study_revision_workflow_v07.pdf workflow. Separate SHA-256 columns bind accepted and public PDF bytes. The v07 workflow contains a Content Credentials attachment: its exact original is preserved privately, while the public PDF removes that attachment and metadata and is pixel-identical at 2x rendering. It is explicitly a sanitized derivative, not byte-identical to the accepted asset. Figures 1, 3 and 4 have paired frozen TeX generators in the V9 archive and are EXACT_FROZEN_SOURCE. Remaining accepted assets are EXACT_STATIC_ACCEPTED_ASSET: the static accepted PDF is retained and no exact layout generator is claimed.

The frozen R1 analyses/reports code supplies scientific plotting logic. The public regenerate_frozen_figures.py wrapper extracts plotting blocks and adapts file I/O; its newly generated plots are RECREATED_SOURCE_ONLY, not original accepted layouts. They must not replace accepted PDFs. Numerical plotting provenance and later editorial re-layout are separate. Legacy aliases are preserved in verification/release_f41a03d/FIGURE_ALIASES.csv.
